# Alpha - 0.2.131 [RU](/ru/changelogs/131)/[EN](/en/changelogs/131)

В Blueprint улучшено редактирование параметров узлов. После отключения связи снова используются заданные пользователем значения, а числовые параметры и длительности получили специализированные редакторы.

---

## Bugfixes/Improvements

* **[Blueprint]** Добавлена проверка настроек узлов. Состояние наблюдения за источником сохраняется во время выполнения действий.
* **[AutoFollow]** Исправлена работа с лестницами и областью клика по переходам.
* **[Scripting]** Уточнены контракты владения в API скриптов и совместимость синтаксиса ReAgent.

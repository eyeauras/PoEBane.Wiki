# Alpha - 0.2.93 [RU](/ru/changelogs/93)/[EN](/en/changelogs/93)

В этом выпуске можно работать с профилями через Aura Library и загружать свои профили после входа в аккаунт. Для настройки автоматизации доступны триггеры Blueprint для Path of Exile 2. Это начальная точка истории изменений — ниже перечислены возможности и исправления, вошедшие в эту сборку.

---

## Bugfixes/Improvements

* **[Core]** Исправлены ошибки жизненного цикла авторизации и лицензирования.
* **[AutoFollow]** Улучшены восстановление следования и отслеживание надписей переходов при наведении курсора.
* **[AI]** В поставку включён полный набор файлов среды выполнения Codex.
* **[Core]** При завершении приложения прекращается повторное согласование состояния функций.

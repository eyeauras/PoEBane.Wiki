# Alpha - 0.2.143 [RU](/ru/changelogs/143)/[EN](/en/changelogs/143)

AutoStash по умолчанию работает в городах и убежищах. Горячие клавиши умений определяются по текущим настройкам игры.

## Bugfixes/Improvements

* **[Input]** Назначения клавиш умений читаются из актуальной конфигурации игры.

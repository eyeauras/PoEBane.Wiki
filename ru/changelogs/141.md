# Alpha - 0.2.141 [RU](/ru/changelogs/141)/[EN](/en/changelogs/141)

## Bugfixes/Improvements

* **[UI]** Исправлены ввод UTF-16, удерживаемые клавиши-модификаторы и работа курсора.
* **[UI]** Исправлены прохождение кликов через оверлей и обработка изменения размера окна.
* **[Input]** Расширена обработка клавиш F13–F24 и команд перехода назад и вперёд.
* **[Studio]** Исправлен выбор ветки Git после запуска для следующего сохранения.

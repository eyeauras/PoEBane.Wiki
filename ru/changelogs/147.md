# Alpha - 0.2.147 [RU](/ru/changelogs/147)/[EN](/en/changelogs/147)

Настройка Formation стала наглядной — область вокруг лидера можно перемещать и менять её размер прямо на сцене. Рядом находятся расстояние, на которое бот может отойти за добычей, радиус остановки и привязка области к направлению взгляда лидера.

---

## Bugfixes/Improvements

* **[Input]** В разделе Automation появился выбор Input method для каждого игрового профиля. Отображается состояние способа ввода; драйвер TetherScript можно установить или удалить с подтверждением прямо из приложения.
* **[Input]** Добавлен Windows Message API для отправки клавиатурных и мышиных сообщений выбранному окну. Поддержка фонового ввода зависит от приложения. Исправлено восстановление ввода после установки выбранного способа и закрытия целевого окна.
* **[Profiles]** Разные профили приложения теперь можно запускать одновременно с раздельными настройками и данными браузера. Обычный повторный запуск того же профиля использует его существующий экземпляр. Перед установкой обновления нужно закрыть другие экземпляры из той же папки приложения.
* **[Startup]** Вход в учётную запись завершается до запуска основных модулей приложения.
* **[AutoQuest]** Обработка заданий теперь заново проверяет текущее окно после каждого действия. Диалоги, награды и выбор NPC больше не зависят от устаревшей последовательности шагов; награды, требующие ручного выбора, оставляются пользователю.
* **[Updates]** В Versions загружаются опубликованные патчноутсы из Wiki с переключением RU/EN. При обновлении через несколько версий показываются изменения всех промежуточных опубликованных релизов.
* **[UI]** Обновлены элементы выбора и числовые поля в настройках профиля и редакторе Blueprint.
* **[MCP/CDP]** Для отдельных экземпляров приложения можно явно задать порты через `--mcp=<port>` и `--cdp=<port>`. Неверные и неподдерживаемые параметры запуска теперь завершаются понятной ошибкой; прежние `--mcp` без порта и `--mcp-port` не принимаются.

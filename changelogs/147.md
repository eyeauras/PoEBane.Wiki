# Alpha - 0.2.147 [RU](/ru/changelogs/147)/[EN](/en/changelogs/147)

Formation settings now have a visual editor — drag and resize the area around the leader directly in the scene. Nearby controls set how far the bot may stray for loot, its stopping radius, and whether the area follows the leader's facing direction.

---

## Bugfixes/Improvements

* **[Input]** Added an Input method selector under Automation for each game profile. It shows the method's status; the TetherScript driver can be installed or removed from the app with confirmation.
* **[Input]** Added Windows Message API to send keyboard and mouse messages to the selected window. Background input support depends on the application. Fixed input recovery after installing the selected method and after the target window closes.
* **[Profiles]** Different application profiles can now run simultaneously with separate settings and browser data. An ordinary repeat launch of the same profile uses its existing instance. Close other instances from the same application folder before installing an update.
* **[Startup]** Account login now completes before the main application modules start.
* **[AutoQuest]** Quest handling now checks the current window again after every action. Dialogues, rewards and NPC selection no longer depend on an outdated sequence of steps; rewards requiring manual selection are left to the user.
* **[Updates]** Versions now loads published Wiki release notes with a RU/EN language switch. Upgrading across several versions shows changes from all intervening published releases.
* **[UI]** Updated selection controls and numeric fields in profile settings and the Blueprint editor.
* **[MCP/CDP]** Separate application instances can use explicit ports through `--mcp=<port>` and `--cdp=<port>`. Invalid and unsupported launch arguments now produce a clear error; the old bare `--mcp` and `--mcp-port` forms are rejected.

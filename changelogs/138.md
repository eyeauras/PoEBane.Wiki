# Alpha - 0.2.138 [RU](/ru/changelogs/138)/[EN](/en/changelogs/138)

Reports can be submitted from the Studio header. Blueprint skill, buff and keyboard handling has been expanded, including separate KeyDown and KeyUp actions.

---

## Bugfixes/Improvements

* **[Reports]** Each report upload has its own identity so another submission does not overwrite it.
* **[Blueprint]** Skill and buff matching supports full names or IDs without case sensitivity.
* **[Blueprint]** Added KeyDown and KeyUp modes to Key Press.
* **[Core]** Fixed a UI-thread shutdown deadlock.
* **[Reports]** Improved diagnosis of native UI and WebView stalls.

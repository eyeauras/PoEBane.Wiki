# Alpha - 0.2.149 [RU](/ru/changelogs/149)/[EN](/en/changelogs/149)

Game profiles now have a Replay section for background recording of the last 5, 10 or 15 minutes of gameplay. Recording works independently of Farm. When you create a report, an available recording is attached while live recording continues. This helps investigate what happened before a problem.

---

## Bugfixes/Improvements

* **[Replay]** Sim Viewer can show recordings alongside held keys, cursor position, and recorded inventory and interaction data. For diagnostics, you can start a fresh bot movement operation at a selected point in the recording; this does not simulate the game's response to new actions.
* **[Updates]** Fixed the transition from the built-in updater in versions 146 and 147 to the new update mechanism.
* **[Updates]** Removed automatic rollback and application termination caused by slow startup after an update. If file replacement fails, the previous executable is preserved or restored; the selected profile is retained on restart.
* **[Input]** Fixed mouse coordinate and keyboard message handling in Windows Message API. Key code conversions are now cached.
* **[Diagnostics]** During UI stalls, logs now capture the window message being processed and the JavaScript execution stage to help pinpoint the stall. The report button has been renamed to **Report...**.

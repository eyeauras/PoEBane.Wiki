# Alpha - 0.2.137 [RU](/ru/changelogs/137)/[EN](/en/changelogs/137)

AutoFollow now supports configurable player selection. AI assistant interaction is centered in Studio — the standalone AI window has been removed.

---

## Bugfixes/Improvements

* **[AutoFollow]** Added player selection settings and selected-target tracking.
* **[AutoFollow]** Stale targets are cancelled before waiting for a passage.
* **[UI]** Fixed shared player selection settings in the UI and DevTree. Added numeric stepper controls.
* **[UI]** Matched the session badge color to the profile color.

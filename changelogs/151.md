# Alpha - 0.2.151 [RU](/ru/changelogs/151)/[EN](/en/changelogs/151)

## Bugfixes/Improvements

* **[Follow]** Reworked recovery when the leader is lost: finding transitions, teleporting through the party UI, and retrying. Updated handling of loading screens and windows that interfere with movement.
* **[Formation]** Added scene zoom, fit-to-view, and settings reset. Fixed manual width and depth entry for the follow area; the area can no longer accidentally be reduced to zero.
* **[Scripts]** Scripts can now create movement, interaction, and input tasks and await their completion. Higher-priority actions can suspend these tasks.
* **[Input]** Fixed the release of held keys and mouse buttons when scripts stop or tasks are interrupted.
* **[Scripts]** Added HTTP requests for fetching external data, such as price catalogs.
* **[Ritual]** Scripts can read rewards, their costs, and the available Tribute in the Ritual window. A ready-to-use automatic buyer is not included in this release.
* **[Character]** Character class and ascendancy are available in scripts, DevTools, and MCP. Added examples of class-based conditions.
* **[Replay]** Recording no longer depends on DevTools being enabled. Recording settings are more compact and include a help tooltip.
* **[UI]** Fixed a hang when closing the application. Improved diagnostics for main-window and script-window stalls.

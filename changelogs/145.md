# Alpha - 0.2.145 [RU](/ru/changelogs/145)/[EN](/en/changelogs/145)

Workspace windows now share a consistent header and a Pin control. The update button shimmers when a new version is available. A suitable profile is selected automatically when attaching to the game.

---

## Bugfixes/Improvements

* **[UI]** Unified workspace window headers and fixed startup handoff. Made capture controls more compact.
* **[Profiles]** Added automatic selection of an eligible profile on attachment.
* **[Scripting]** Fixed sequential Sleep and WaitUntil execution. Script-owned input is released on completion or cancellation.
* **[AutoFollow]** Game windows are closed before following using the current close-all-windows binding.
* **[DevTree]** Updated inspection of generated entity data.

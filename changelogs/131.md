# Alpha - 0.2.131 [RU](/ru/changelogs/131)/[EN](/en/changelogs/131)

Blueprint node parameter editing has been improved. Disconnecting a link restores user-entered values, and numeric and duration parameters have dedicated editors.

---

## Bugfixes/Improvements

* **[Blueprint]** Added node configuration validation. Source observation state is preserved while actions run.
* **[AutoFollow]** Fixed stair traversal and transition click bounds.
* **[Scripting]** Clarified script API ownership contracts and ReAgent syntax compatibility.
